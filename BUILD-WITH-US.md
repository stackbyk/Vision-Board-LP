# Why build with us

This section is part of the existing buildless landing page. Open index.html directly or use the existing local server at http://localhost:3000/.

Edit copy in buildBenefits at the top of build-with-us.js. Change scoped brand variables and circle dimensions in build-with-us.css. CYCLE_MS controls the four-second rotation; RESUME_MS controls the six-second delay after interaction.

Circles support click, desktop hover, Tab, arrow keys, Enter and Space. Rotation pauses while the circles are hovered or focused, offscreen, or in a hidden tab. Reduced motion disables automatic rotation and decorative motion. Update the I Want To Create Mine href in index.html when a booking link is available.

The section uses a plain white background and no detail strip or decorative effects. All active numbers and progress rings share --number-highlight. The .build-content wrapper keeps text within 68% of each circle; circles overlap by 11%.
